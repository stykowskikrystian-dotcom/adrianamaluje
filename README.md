# Adriana Maluje

Strona wizytówkowa Adriany Bękalskiej, makijażystki z Giżycka.

## Uruchomienie lokalne

Projekt jest statyczny i nie wymaga instalowania zależności.

```bash
python -m http.server 4173
```

Następnie otwórz `http://localhost:4173`.

## Wdrożenie na Vercel

Repozytorium można zaimportować bezpośrednio do Vercela. Framework Preset pozostaw jako `Other`, a katalog główny jako `./`. Projekt nie wymaga polecenia budowania ani katalogu wynikowego.

Konfiguracja nagłówków i pamięci podręcznej znajduje się w `vercel.json`.
